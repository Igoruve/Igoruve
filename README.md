# Holi! mi nombre es Igor :D
Soy un desarrollador frontend con una sólida formación en Bellas Artes (BBAA), lo que me brinda una perspectiva única para combinar funcionalidad técnica con un diseño estético y cuidado. Mi experiencia se centra en el desarrollo de interfaces web modernas, accesibles y eficientes, siempre buscando la mejor experiencia para el usuario.

## Sobre mí
Mi formación en Bellas Artes me ha permitido desarrollar un sentido agudo para el diseño, la composición visual y la creatividad, habilidades que aplico directamente en mis proyectos de frontend. Esta combinación de técnica y arte me permite crear soluciones web que no solo funcionan bien, sino que también son visualmente atractivas y coherentes con las necesidades del usuario.

## Habilidades principales
- Desarrollo frontend: HTML5, Tailwind CSS, JavaScript (ES6+), frameworks y librerías modernas como React.
- Diseño UI/UX: aplicando principios de diseño gráfico y experiencia de usuario para mejorar la interacción.
- Herramientas de diseño: experiencia con software de diseño digital, basado en mi formación en Bellas Artes.
- Responsive design y accesibilidad: garantizando que las aplicaciones sean usables en diferentes dispositivos y para todo tipo de usuarios.

Mi objetivo es seguir creciendo como profesional en el desarrollo frontend, integrando siempre los valores estéticos y funcionales para construir productos digitales que destaquen por su calidad técnica y visual. Estoy interesado en proyectos que valoren la unión entre el diseño y la tecnología para crear experiencias digitales impactantes y efectivas.
